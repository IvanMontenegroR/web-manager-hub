# Web Manager Hub

Herramienta interna de gestion de proyectos web (Nestle Purina LATAM). React + Vite +
Supabase, hosteada en GitHub Pages con redeploy automatico en cada push.

Modulo activo: **Web Projects** (Gantt maestro por dia, deteccion de solapamientos por
partner, retrasos con razon, CRUD completo y export a Excel).

Live: https://ivanmontenegror.github.io/web-manager-hub/

Ver [CLAUDE.md](./CLAUDE.md) para stack, esquema, logica y como correr/deployar.
